Recalculate penalties

If a loan's due date or terms were edited, or penalty settings changed, after penalties were already charged, stale over-charges can build up - the regular check only ever adds new penalties, it never removes outdated ones. This wipes every unpaid, unwaived penalty and rebuilds the correct set from scratch, using each member's current contribution standing and each loan's current terms. Penalties already marked paid or waived are never touched.

Wipe all penalties and start fresh

A more drastic reset - deletes every penalty, including ones already marked paid or waived, then rebuilds from scratch based on current standing. Use this only if you want a completely clean slate; it erases the historical record of which penalties were previously paid or waived, so any past penalty payment will no longer show as settled.
