Fresh start - clear the slate

A plain "wipe" deletes penalties and then rebuilds the same ones straight away, because the contribution and loan history still says those members were short or overdue. A fresh start avoids that: it deletes every penalty and sets today as the date penalties begin, so nothing from before today is ever counted.

  • Every existing penalty is deleted (paid and waived ones too).
  • Late contributions: counting starts from this month. Nobody is penalised for earlier shortfall, and anyone who had paid ahead keeps that credit.
  • Overdue loans: only months overdue after today attract the KES penalty. The loan still shows as overdue - it just carries no penalty for the past.

Recalculate penalties

If a loan's due date or terms were edited, or penalty settings changed, after penalties were already charged, stale over-charges can build up - the regular check only ever adds new penalties, it never removes outdated ones. This wipes every unpaid, unwaived penalty and rebuilds the correct set from scratch, using each member's current contribution standing and each loan's current terms. Penalties already marked paid or waived are never touched.

Reset late-contribution penalties only

Deletes every late-contribution penalty and recalculates them from scratch for each member:
months elapsed since joining (not counting the current month) × the minimum monthly contribution = amount expected by now.
Expected − what they've actually contributed = shortfall.
Penalty = shortfall ÷ minimum contribution (rounded up to whole months) × the penalty amount. A member who is caught up gets no penalty at all.

Overdue-loan penalties are not touched. This also removes late-contribution penalties that were already marked paid or waived, so note down any you need to remember first.

Wipe all penalties and start fresh

A more drastic reset - deletes every penalty, including ones already marked paid or waived, then rebuilds from scratch based on current standing. Use this only if you want a completely clean slate; it erases the historical record of which penalties were previously paid or waived, so any past penalty payment will no longer show as settled.
